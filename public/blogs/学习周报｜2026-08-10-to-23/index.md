## 1. 本周技术学习总结

### 运行一个ai写好的python项目

`uv sync` and `uv sync --locked`

uv 是 Python 项目的环境管理工具。我们通常在项目根目录中打开PowerShell，然后运行这个程序。
运行后它会检查我的电脑现在的环境是不是符合项目要求。
如果缺少：

安装。

如果版本不对：

调整。

如果已经正确：

保持。

```powershell
Resolved 114 packages in 1ms
Checked 514 packages in 2ms
```

第一行：计算出了这个项目需要的 114 个 Python 包。
第二行：检查了当前环境里的 514 个包。

| 命令                 | 含义          | 是否更新锁文件           |
| ------------------ | ----------- | ----------------- |
| `uv sync`          | 正常同步环境      | ✅ 可以更新 `uv.lock`  |
| `uv sync --locked` | 严格按照已有锁文件安装 | ❌ 不允许修改 `uv.lock` |

如果我修改了pyproject.toml，`uv sync`会帮我修改`uv.lock`文件以适应情况；`uv sync --locked`会报错。

### 如何与ai协作？

对于做项目，首先，自己要出一个mvp方案，让一个agent做好初始化：
1.确认架构。
2.搭框架，建好各个模块的文件夹。
3.明确各部分输入输出，如何传递，传递给谁。
然后根据每个子模块功能做分支，独立开发每个子模块。
最后由最早的session合并分支，并做最终整合开发。如果要开发GUI，那么也是在这一步开发。

## 2. 遇到的问题

### 问题 1：如何基于AI生成的项目文件进行源码调试

**现象：**

有时候ai写出来的代码，如果由人工完全负责测试，则会非常耗时耗力/


**解决方案：**

我认为在验收阶段，应当进行好分工，哪些部分由人工来进行检查，哪些部分由agent检查。
我认为应当有以下原则：
AI 可以承担测试、静态检查、代码审查等重复工作，但涉及业务意图、架构取舍、安全风险时仍需要人工判断。
人工审查应当注重以下方面：
1.功能是否符合需求。（人工直接进行成果测试）
2.系统设计是否合理，架构选择是否正确。（让ai输出现有架构，然后与另一个ai进行讨论）
3.核心业务逻辑是否正确。（让ai输出流程图）
4.风险判断。这种在机器学习相关开发中尤其需要注意。未来函数，数据泄露，样本偏差，市场环境变化都是要考虑的点。

### 问题 2：如何利用ai进行研究问题探讨，并且产出论文。
**现象：**
AI有时候出的方案不基于现有数据，想法天马行空。
**解决方案：**
数据采集和科研框架要自己搭，其余再由ai实现。

### 问题 3：我采取一个agent出方案，每个模块由不同的agent执行的模式coding，导致很难实现效果。
**现象：**
我先与LeaderAI一起讨论技术实现。再用一个agent写后端，一个agent写GUI的形式进行coding。结果导致后端与GUI衔接特别生硬，很多功能缺失。
**解决方案：**
合理采用分支功能，由同一个session派生出两个新的session，各自维护一个版本，完成对应功能后提交PR，由原session进行合并，归档两个并行session，继续使用主session。

### 问题 4：没做好版本隔离，直接利用多个agent在同一个版本里面实现不同功能
**现象：**
我让两个agent在一个版本里面同时完成前后端开发，导致版本混乱。
**解决方案：**
下次需要建立新的文件夹，让agent维护不同的文件夹，完成各自模块后原子化提交PR，并且补充好对应回归测试，由新的agent合并。

### 问题 5：我没有做好数据来源调研，让agent随便找了几个数据来源调用
**现象：**
我没有做好数据来源调研，让agent随便找了几个数据来源调用，导致获取缓慢，程序几乎跑不起来。
**解决方案：**
与架构的选择一样，agent不明白我们的需求，无法为我们做出最好的数据来源选择。所以无论是数据来源调研，还是架构调研，最终的选择与敲定都要由我们自己来做。

## 3. 本周认知与感悟

1.行止有度。不能忽略身体健康蛮干。
2.现在ai能够帮助我们快速产出代码。但是其在理解人类意图，进行规划决策以完成项目方面，还是有一定缺陷。举个例子：我用gpt5.6来全权完成一个kaggle项目，它时常会混淆目标与测试指标，对于测试指标设计不够严谨，导致整体实验与目标偏差。最后为了完成指标而工作，产出的模型绝大多数不满足指标。即便满足了也与目标有偏离。需要人类来设计和规划。
